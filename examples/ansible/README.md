# Параметризованный Docker Compose для Ansible

`monitor-agent.compose.yml.j2` — исходный шаблон роли установки агента мониторинга.
Он демонстрирует параметризацию образа/имени, env-file и ротацию логов.
Значения переменных, `.env`, inventory и данные серверов не приложены.

Шаблон использует host networking и Docker socket для сбора метрик хоста.
Монтирование Docker socket с `:ro` **не делает Docker API доступным только для чтения**.
При эксплуатации такой агент является доверенным компонентом с широким доступом;
для более строгой изоляции нужен ограничивающий API proxy или другая схема сбора.
