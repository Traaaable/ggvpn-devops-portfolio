# Отчёт проверки

Дата: **20 октября 2026 года** (Омск, UTC+6).

Локальная среда: Docker Engine 28.3.2, Helm 4.3.1,
Kubernetes 1.35.5+k3s1 в существующем k3d-кластере.
Все изменения Kubernetes выполнялись в новых временных namespace.
Рабочие приложения и существующие релизы не обновлялись.

| Проверка | Результат |
|---|---|
| `helm lint --strict`: default, dev, ingress + HPA + NetworkPolicy | PASS |
| 9 контрактных тестов, включая разные release names и ConfigMap | PASS |
| Kubernetes API dry-run для default и набора опциональных ресурсов | PASS |
| Docker Compose: build, healthcheck, HTTP, UID 101, read-only rootfs | PASS |
| Установка двух независимых Helm-релизов | PASS |

| Upgrade содержимого страницы и порта Service | PASS |
| Намеренно отсутствующий образ → неудачный upgrade → rollback → Helm test | PASS |
| Pod Security `restricted`, запрет записи в `/etc` | PASS |
| Ingress HTTP через установленный Traefik | PASS |

HPA проверялся искусственной CPU-нагрузкой в одном контейнере с лимитом 200m
и таймаутом процесса 65 секунд. Это не измерение RPS, числа пользователей
или числа платящих клиентов.

Границы проверки:

- Nginx Ingress проверен на уровне шаблона/API. HTTP-проверка использовала
  установленный Traefik; Nginx-контроллер ради стенда не устанавливался.
- TLS-параметры есть в chart; реальный выпуск и продление сертификата не проверялись.
- HPA scale-up проверен; стабилизация scale-down и длительное поведение под нагрузкой не измерялись.
- PDB создан и принят API; drain узла и потеря узла не выполнялись.
- Исходящая блокировка NetworkPolicy присутствует в манифесте; отдельный тест egress не выполнялся.
- DNSTT не проверялся сквозным клиентским соединением через публичный DNS.
- Фрагменты GG VPN app и Ansible требуют исходного проекта/переменных.
  Полный VPN backend по ним не разворачивался.
- Сканирование секретов не является аудитом всех уязвимостей приложения
  или зависимостей.

GitHub Actions проверяет chart на Helm 3 и 4, сборки Docker и жизненный цикл
релиза в отдельном kind-кластере. Результаты внешних запусков доступны во
вкладке Actions репозитория; локальные проверки выше выполнены отдельно.
